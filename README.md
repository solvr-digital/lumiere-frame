# 📸 Lumière Frame

> **Stories, captured in light.**

A cinematic and immersive photography portfolio website designed for a premium photography brand. The website focuses on visual storytelling through smooth scroll animations, interactive galleries, parallax effects, and editorial-style layouts.

## ✨ Features

- 🎞️ Cinematic hero section
- 🖼️ Scroll-driven image animations
- ✨ Smooth image reveal effects
- 🔄 Parallax photography sections
- ↔️ Horizontal scrolling gallery
- 🔍 Fullscreen image lightbox
- 🖱️ Custom interactive cursor
- 🎨 Editorial luxury design
- 📱 Fully responsive layout
- ⚡ Smooth scrolling and optimized animations
- 💫 Interactive hover effects
- 📸 Photography categories and galleries

## 🛠️ Tech Stack

- React
- JavaScript
- Tailwind CSS
- GSAP
- GSAP ScrollTrigger
- Framer Motion
- Vite

## 🎯 Concept

Lumière Frame is designed as more than a traditional photography portfolio.

The experience uses cinematic transitions and scroll-based storytelling to make every photograph feel like part of a visual journey.
